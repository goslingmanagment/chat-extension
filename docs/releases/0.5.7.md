# Выпуск 0.5.7

Заметка выпуска: выполненные проверки и явно указанные исключения по просьбе
владельца шипнуть без дополнительных локальных тестов. Порядок выпуска —
`docs/release.md`; обязательный CI main остаётся условием подписи.

## Перед подписью

- [x] `smoke` — Проверен код всей цепочки: UI/операция → MAIN → схема → политика → тело запроса → обработчик хаба. Локально выполнены typecheck, линт затронутого и сборка; тесты не запускались по просьбе владельца. Ручной smoke в живом аккаунте не выполнялся. Firefox MV3 проверяет обязательный CI main.
- [x] `perf` — Отдельный Perf не запускался по той же просьбе владельца. Новых фоновых опросов и сетевых чтений Fansly нет: используются существующие снимки текущего чата, максимум 60 сообщений. Для анкеты и операции текста войса снимок берётся при старте.
- [x] `hub-383` — Доступ к персонам не меняется; используются пути предыдущего выпуска.
- [x] `hub-state` — hub#681 слит в `74c0f32251b633b76e0eb06f4c0e0762ae31eae2`, CI main зелёный, штатный деплой завершён 2026-10-20 13:30 UTC. В коде работающего API есть `live-text-fansly-tools-v1`. Read-only SQL подтвердил `aiLiveTextContextMode=serve` и `freshText=true` у всех восьми включённых пилотных страниц. SDK закреплён на этом коммите; онлайн-гейт дополнительно проверяет совместимость. Штатная проверка sync получила 503 с данными страниц; восстановление фоновой синхронизации в этот выпуск не входит.
- [x] `bindings` — Привязки страниц не меняются. Свежий текст принимается только для совпадающих аккаунта, фана и разговора; смена чата во время снимка отменяет старт анкеты/текста войса.
- [x] `texts` — Раздел 0.5.7 прочитан, страницы созданы `pnpm release site`; правило записано в X70 и FS-TAIL-10. Необязательные поля контрактов 1.42.0 совместимы со старыми стартами.

Проверены Reply, Fix, Hi, Ping, Review, Coach, обе сводки и автоматическая сводка перед
Coach, заполнение анкеты и существующая операция текста войса. Панель записи войса
этим выпуском не добавляется. Превью неоткрытого ChatSpace-чата по-прежнему использует
архив: чтение такого чата отмечает его прочитанным. Если снимок недоступен или
возможность выключена, остаётся предусмотренный fallback на архив.
