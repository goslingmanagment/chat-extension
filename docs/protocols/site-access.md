# `site.access` — доступ к опциональному сайту (1.15.0, P9a)

Схемы: `packages/contracts/src/site-access.ts`. Запрос — общий реестр `TAB_REQUESTS`,
отправитель `page`, только страницы `popup` и `options`. Вкладки сайта, relay и страницы
отладки не допущены. Сейчас фон обслуживает только опциональный хост `fansly-web`.

| Поле запроса | Значение |
|---|---|
| `host` | `HostKind`, обязательное |
| `enabled?` | boolean: записать переключатель сайта в `settings.ext` |
| `reload?` | boolean: при `true` перезагрузить ожидающие вкладки после применения `enabled`, если оно задано |

Без действия запрос читает уже синхронизированное состояние: он не вызывает регистрацию
скриптов, захват сессии или запись хранилища. Синхронизация происходит на старте фона,
при install/update, выдаче/отзыве прав и изменении переключателя сайта. Изменения других
настроек не трогают регистрацию. Запрос прав Firefox делает сама страница из исходного
клика, до ожидания RPC; набор прав общий у страницы и проверки фона.

| Поле ответа | Значение |
|---|---|
| `host` | Хост запроса |
| `enabled` | Сохранённый переключатель |
| `granted` | Выдан весь набор опциональных прав |
| `registered` | Скрипты зарегистрированы и сайт активен |
| `waitingReload` | Число вкладок, ожидающих перезагрузки; при отзыве прав — 0 |
| `reloaded?` | Только результат `reload`: число успешно принятых браузером перезагрузок |

Перезагрузка — только по нажатию человека. Каждая вкладка завершается отдельно:
успешные убираются из ожидающих, исчезнувшие удаляются, оставшиеся неудачные можно
повторить следующим нажатием. Один закрывшийся таб не отменяет остальные. Успешный
вызов `tabs.reload` ещё не означает успешное рукопожатие или захват новой сессии.

Нет сессии, токенов, заголовков или текста чата в запросе и ответе. Необслуживаемый хост —
`CG-UNKNOWN`; сбой фоновой операции — `CG-RUNTIME-UNREACHABLE`. Частичный успех
перезагрузки — обычный ответ со счётчиками. Старые формы без `reloaded` остаются валидными;
фикстуры включают обе формы и отвергают отрицательные счётчики.
