# P9e — Spenders на Fansly

Снимки настоящей тестовой MV3-сборки в Firefox 156 на изолированном loopback-стенде, 1440 × 900.
Данные синтетические, хаб поддельный; живой Fansly не использовался.

- [Светлая тема](spenders-fansly-p9e-bright.png).
- [Тёмная тема](spenders-fansly-p9e-dark.png).

Вручную проверены оба изображения: доска и превью помещаются в окно, текст и кнопки читаются,
статистики и её колонки нет. Под частью Reply — «Открыть и вставить» и копирование; «Отправить» нет.

`suite-fansly-ids.e2e.ts` проверяет группу из строки хаба, пассивного кэша страницы, одного поиска и
одной попытки POST `/group`; Reply из превью и вставку в группу другого фана, отсутствие собственных
отправок и `ack`. Пассивное превью не делает запросов к Fansly. Собственные запросы идут через
allowlist и пейсер P9b; в тестовой сборке отсутствие loopback-адреса отказывает до сети.
