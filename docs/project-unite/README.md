# Project Unite

Клиенты ChatGoose объединяются в одно расширение — это. Первый шаг — R20: второй хост, fansly.com, вместо
Fansly-расширения (`~/code/1-platform/fansly-chat`). Десктоп OnlyFans (`~/code/1-platform/onlyfans-chat`)
выводится по своим критериям (X5) и в эту папку пока не входит.

## Как получились документы

1. **Вопрос владельца**: есть ли смысл объединять Fansly-расширение с этим и не будет ли проблем с
   производительностью и архитектурой.
2. **Сбор доказательств.** Codex скачал бандл fansly.com (без cookies, без запросов к API) и снял
   обезличенный снимок открытого чата; владелец снял живой замер в Firefox 157 скриптом из консоли.
   Задержку сокетного оверлея хаба и точность id координатор проверил на проде, только чтением.
3. **Арена** Opus 5.5 + astra (effort max): вопросы владельцу, два независимых плана, сверка, сводный план,
   подписанный обоими с правками.
4. **Решения владельца** — X33: хвосты не теряются, полный паритет 2.8.1, «Fansly через вкладку» —
   опционально, «Регистрация» — в шапке, параллельные генерации.
5. **Спецификация и план v1 → три ревью astra** (Codex gpt-6-astra, effort max, одна сессия). Каждое
   замечание проверено по коду; ни одно не оказалось ложным.
6. **Ответы владельца** — X34 (быстрый переход, без живого Fansly, пилот `lora-1` и `ari-1`, «Заметки» в
   пилоте, глубина Recap 5000).
7. **Семь исследований** (Opus 5.5, параллельно): код расширения — контракты и хост (S1a), ядро, UI и тесты (S1b);
   бандл fansly.com (S2); старое расширение (S3); хаб и прод (S4, только чтение); FBuddy (S5); Firefox (S6). По
   ним — архитектура и план v6 (X35). Главное, что они изменили: у ChatSpace почти нет запаса по размеру и фон
   упирается в потолок архива; правило Hi «по истории хаба» отказывало бы почти всем новым чатам; FBuddy
   обёртывает XHR, а не WebSocket, и может «проглотить» отправку; шапка чата пересоздаётся при смене чата;
   старое уже на 2.10.1.
8. **Арена-ревью архитектуры и плана v6** (Opus 5.5 + astra, max): два независимых отчёта, затем сверка — один
   общий список правок (X36), документы — v7; затем оба проверили сведённый результат и указали, где перенос неполон
   (исправлено). Оба участника: «не готов по текущему плану», устройство при этом верное; возражений к выбору
   координатора нет. Решающие утверждения координатор перепроверил по коду, бандлу и проду (только чтение).
9. **Ответы владельца по итогам арены** — X37 (2026-10-13): пилот — все шесть страниц Fansly и все 11 чаттеров
   сразу; глубину Recap в хабе агент по его просьбе поднял до 3000; остальные предложения §15.1 приняты.
