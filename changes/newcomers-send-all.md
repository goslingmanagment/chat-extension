# «Новые»: «Отправить всем» отправляет готовые приветствия по одному, с паузой в секунду

Раньше каждое приветствие из пакета приходилось отправлять своей кнопкой «Отправить» в строке фана. Теперь, когда
пакет готов, внизу списка есть кнопка «Отправить всем (N)»: выберите фанов, нажмите «Сгенерировать», прочтите
черновики и нажмите её один раз. Приветствия уйдут по очереди, по одному в секунду, а под списком видно, сколько
уже ушло. Окно браузера можно свернуть: отправка не остановится. «Остановить отправку» прерывает её, неотправленные
черновики остаются в строках.

![«Новые»: пакет приветствий готов, внизу «Отправить всем (8)»](newcomers-send-all.png)

## Как это устроено

Каждое приветствие уходит так же, как его кнопка «Отправить» в строке, с теми же проверками. Хаб пропускает не больше
30 отправок в минуту, поэтому на 31-й отправка ждёт, пока освободится минута, и продолжает сама. Приветствие, которое
не ушло или ушло с неизвестным итогом, второй раз не отправляется: в его строке написано почему, решаете вы. Черновик,
вставленный через «Открыть и вставить», и строки с предупреждением (фан написал что-то новое) пропускаются. Итог
под списком считается по строкам: «Отправлено N из M», и сколько не ушло.
