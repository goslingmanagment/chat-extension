# Кнопки под вариантами Hi помещаются в карточку

Для тех, у кого поле чата средней ширины: Hi ставит три варианта рядом, и кнопка «Вставить» вылезала за край
карточки. Теперь в узкой колонке «Копировать» — значок с подсказкой, а «Вставить» стоит рядом с ним внутри
карточки. На широком поле «Копировать» по-прежнему написано словом.

![Hi на поле шириной ~700 px: три варианта, кнопки внутри карточек](hi-variants-fit.png)

## Как это устроено

Колонка варианта сама решает по своей ширине: уже 280 px — «Копировать» значком. Если кнопки всё равно не
помещаются (например, «✓ Вставлено · Вставить ещё раз»), они переносятся на вторую строку, а не выходят за край.
