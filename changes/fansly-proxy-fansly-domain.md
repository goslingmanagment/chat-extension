# Прокси модели больше не просит доступ ко всем сайтам

Для настройки «Весь трафик через прокси модели» Firefox спрашивал доступ ко всем сайтам. Теперь только к сайтам fansly.com и к настройкам прокси, как у FBuddy. Через прокси модели по-прежнему идут сам Fansly, FBuddy и запросы ChatGoose.

Если вы уже разрешили доступ ко всем сайтам, ChatGoose сам откажется от него после обновления. На вкладке Fansly снова появится подсказка: один раз нажмите «Разрешить», и Firefox спросит уже только про fansly.com.

![Настройка в разделе «Аккаунты»: Firefox спросит доступ только к fansly.com](fansly-proxy-fansly-domain.png)

## Как это устроено

Firefox отдаёт запрос прокси-фильтру расширения, если у расширения есть доступ к адресу этого запроса, а кто его отправил (вкладка, service worker Fansly, FBuddy, фон ChatGoose), не проверяет. Все запросы без вкладки, которые раньше уходили мимо прокси, идут на адреса *.fansly.com, поэтому домена Fansly хватает. Запросы вкладки модели к сторонним сервисам на страницах Fansly (чат поддержки, аналитика) по-прежнему ведёт прокси контейнера в Multi-Account Containers. Доступ ко всем сайтам из прошлой версии ChatGoose снимает сам при запуске.
